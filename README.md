# Code Studio

Website sederhana untuk Code Studio, layanan desain dan pengembangan website untuk bisnis. Proyek ini dibuat menggunakan HTML, CSS, dan JavaScript tanpa framework.

## Halaman

- **Beranda** (`index.html`) — menampilkan layanan desain, pembuatan, dan perawatan website.
- **Tentang** (`tentang.html`) — memperkenalkan Code Studio dan pencapaiannya.
- **Kontak** (`kontak.html`) — menyediakan formulir untuk mengisi nama, email, subjek, dan pesan. Formulir saat ini hanya melakukan validasi di browser dan belum terhubung ke layanan pengiriman pesan.

## Menjalankan proyek

Tidak perlu memasang dependensi. Buka `index.html` di browser untuk melihat website. Untuk menjalankan melalui server lokal, buka folder proyek di editor dan gunakan ekstensi server lokal seperti Live Server.
